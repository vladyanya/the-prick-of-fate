# Укол судьбы · the prick of fate

Интерактивная арт-открытка в русском фолк-коде: резной наличник-портал, а за его стеклом — гадание на ромашке «любит / не любит».

## О чём это

Маленькая история про нездоровую любовь-гадание. Если приходится обрывать лепестки и *надеяться*, что тебя любят, — сама эта неуверенность уже ответ. 

## Как открыть

Открой `index.html` в браузере — зависимостей и сборки нет, всё лежит в одном файле (HTML + inline SVG + CSS + JS). Заголовочный шрифт подгружается с Google Fonts, поэтому для него нужен интернет; без сети подставится системный serif, остальное работает офлайн.

## Взаимодействие

- Нажми на тёмное стекло — портал мягко затягивает внутрь.
- На пару секунд проступает фигура в косынке и растворяется, превращаясь в кружевную красную ромашку.
- Обрывай лепестки (тап по всему цветку) — наверху сменяется «любит / не любит», за каждый лепесток срывается капля крови.
- Когда лепестков не остаётся — финал. Исход гадания честный, 50/50.

Адаптировано под мобильный. Учитывает `prefers-reduced-motion`.

## Стек

Чистый vanilla: HTML, инлайновый SVG, CSS, немного JavaScript (Web Animations API). Ни фреймворков, ни сборки, ни зависимостей — один самодостаточный файл.
