# Укол судьбы

Интерактивная арт-открытка в русском фолк-коде: резной наличник-портал, а за его стеклом — гадание на ромашке «любит / не любит».

## О чём это

Маленькая история про нездоровую любовь-гадание. Если приходится обрывать лепестки и *надеяться*, что тебя любят, — сама эта неуверенность уже ответ. Работа не судит и не морализирует: в финале — не приговор, а тихое пожелание.

## Как открыть

Просто открой `index.html` в браузере — зависимостей и сборки нет, всё лежит в одном файле (HTML + inline SVG + CSS + JS). Заголовочный шрифт (Ruslan Display) и текст (Forum) подгружаются с Google Fonts, поэтому для «фолк»-заголовка нужен интернет; без него подставится системный serif, всё остальное работает офлайн.

## Взаимодействие

- Нажми на тёмное стекло — портал мягко «затягивает» внутрь.
- На пару секунд проступает фигура в косынке и растворяется, превращаясь в кружевную красную ромашку.
- Обрывай лепестки (тап по всему цветку) — наверху сменяется «любит / не любит», за каждый лепесток срывается капля крови и внизу копится лужа.
- Когда лепестков не остаётся — финал.

Исход гадания честный, 50/50. Адаптировано под мобильный экран. Учитывает системную настройку `prefers-reduced-motion` (для тех, у кого анимации отключены).

## Стек

Чистый vanilla: HTML, инлайновый SVG, CSS, немного JavaScript (Web Animations API для порхания лепестков). Ни фреймворков, ни сборки, ни зависимостей — один самодостаточный файл.

## Публикация на GitHub Pages

Так как это единственный `index.html`, страницу можно опубликовать в один клик: **Settings → Pages → Deploy from a branch → main / root**. Через минуту работа будет доступна по ссылке вида `https://<username>.github.io/ukol-sudby/`.
