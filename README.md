# Укол судьбы

Интерактивная арт-открытка: резной наличник, а за стеклом — гадание на ромашке «любит / не любит». Обрываешь лепестки, за каждый капает кровь. Одна страница, чистый vanilla, всё в одном файле.

Живьём → https://vladyanya.github.io/the-prick-of-fate/

## Что происходит

Жмёшь на стекло — затягивает внутрь. Проступает вышивальщица и тает; на её месте игла делает укол, и из капли крови распускается ромашка. Дальше гадаешь — тап по цветку срывает лепесток. Лепестки кончились — выпадает исход и пожелание.

Гадание честное, 50/50. По мотиву легенды про укол иглой, каплю крови и цветок.

## Запуск

Открой `index.html` в браузере. Всё. Ни сборки, ни бандлера, ни зависимостей — один файл. Шрифты вшиты внутрь, работает даже без сети.

## Под капотом

Vanilla HTML, inline SVG, CSS, немного JS (Web Animations API). Никаких фреймворков. Стекло и дисторшн — SVG-фильтры (`feDisplacementMap`, `feTurbulence`); кровь слипается в лужу через gooey (`feGaussianBlur` + `feColorMatrix`). Есть `prefers-reduced-motion`.
